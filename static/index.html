01. Read-Only Permission & Data Processing Boundary

          

            

              OAuth Scope Grant: Requests only https://www.googleapis.com/auth/drive.readonly. No write, edit, create, move, or delete permissions are requested or granted.
            

            

              Session Persistence: Enforces Firebase inMemoryPersistence (await setPersistence(auth, inMemoryPersistence)) and holds the OAuth token solely in a JavaScript variable. Reloading the tab clears the session completely.
            

            

              Document Body Processing: Exported Google Docs bodies are compared in-browser by default, or—when Python backend verification is selected—processed on your local computer (localhost) or sent to the hosting backend when running on a hosted preview URL.
